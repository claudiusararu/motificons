# Motificons

Every open-source icon - customizable, exportable for web AND native (JSX + SwiftUI), searchable by humans on the web and by coding agents over MCP. Free, and open source itself.

## Docs
- [AGENTS.md](AGENTS.md) - conventions for working in this repo: layout, commands, gates, and the rules every change follows. Read first.

## Quick facts
- Price: free. No paid tier, no subscription, nothing to buy.
- Open browse pages - icon, set and category - are never gated or metered. Only the search box is metered, and only for visitors without an account (25 queries a day).
- A free account lifts the search limit and adds 5 collections plus an MCP key for coding agents.
- The MCP server is live at mcp.motificons.app, free with an account.
- Style engine: cross-set normalization, style match and detail-page quick edit, so icons from different sets can be made to look like one system.
- Native output other aggregators do not offer: SwiftUI code and Xcode asset catalogs, alongside React, Vue, Svelte, PNG and CSS.
- A macOS app with Spotlight-style search, offline, free to download.
